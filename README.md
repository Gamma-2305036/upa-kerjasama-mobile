# UPA Kerjasama Mobile

Aplikasi mobile untuk portal karir POLINDRA yang memudahkan mahasiswa mencari lowongan kerja dan informasi perusahaan.

## 🚀 Features

- **Login System** - Login dengan email/password atau Google
- **Beranda** - Menampilkan lowongan kerja terbaru
- **List Perusahaan** - Daftar perusahaan dengan rating dan detail
- **Profile** - Manajemen profil pengguna
- **Smooth Navigation** - Navigasi yang halus dengan PageView

## 📦 Installation

1. Clone repository:
```bash
git clone https://github.com/yourusername/upa-kerjasama-mobile.git
cd upa-kerjasama-mobile
```

2. Install dependencies:
```bash
flutter pub get
```

3. Run the app:
```bash
flutter run
```

## 🏗️ Project Structure

```
lib/
├── components/
│   ├── main_navigation.dart    # Main navigation wrapper
│   └── navigation.dart         # Bottom navigation bar
```
